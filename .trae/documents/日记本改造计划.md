# 日记本改造计划

## 摘要

将现有的 Twitter/X 克隆改造成"推特形式的日记本"。核心变化：

1. 发帖时可选"随想"或"日记"两种类型
2. 卡片上显示类型标签和完整日期时间
3. 支持单条帖子导出为 Markdown
4. 支持批量导出（全部/按类型/按时间筛选）

## 当前状态分析

项目使用 Next.js 14 + TypeScript + Tailwind CSS，已有完整的 Feed、发帖、个人资料、Context 状态管理。

需要改造的文件：

* `lib/types.ts` — Post 类型增加 `entryType` 和 `title` 字段

* `lib/context.tsx` — `addPost` 增加类型参数

* `lib/mockData.ts` — 给现有帖子分配类型，新增日记类 mock 数据

* `components/post/ComposeModal.tsx` — 发帖弹窗增加类型选择 + 日记标题输入

* `components/feed/PostCard.tsx` — 卡片显示类型标签 + 完整日期时间

* `components/ui/ExportButton.tsx` — 新增单条导出按钮组件

* `app/profile/page.tsx` — 增加批量导出按钮和筛选选项

* `lib/export.ts` — 新增 Markdown 导出工具函数

***

## 详细改造方案

### 1. 类型定义扩展（lib/types.ts）

**新增类型：**

```ts
export type EntryType = 'thought' | 'diary';

export interface Post {
  id: string;
  userId: string;
  entryType: EntryType;      // 新增：'thought' 随想 | 'diary' 日记
  title?: string;            // 新增：日记标题（可选）
  content: string;
  images: string[];
  createdAt: string;
  replies: Reply[];
  reposts: number;
  likes: Like[];
  views: number;
  isReposted: boolean;
}
```

**修改** **`FeedTab`：**

```ts
export type FeedTab = 'all' | 'thought' | 'diary';
```

### 2. Context 状态管理更新（lib/context.tsx）

**修改** **`addPost`** **签名：**

```ts
addPost: (content: string, images: string[], entryType: EntryType, title?: string) => void
```

**创建新帖子时设置** **`entryType`** **和** **`title`。**

**新增导出相关函数：**

```ts
exportPostAsMarkdown: (post: Post) => void
exportPostsAsMarkdown: (posts: Post[], filename?: string) => void
```

### 3. Markdown 导出工具（lib/export.ts）

**单条导出格式：**

```markdown
# [日记标题]

> 类型：日记 | 时间：2025年4月28日 14:30

正文内容...

---
发表于 2025-04-28T14:30:00Z
```

**批量导出格式：**

```markdown
# 我的日记本导出

生成时间：2025-04-28

---

## [日记标题]

> 类型：日记 | 时间：2025年4月28日 14:30

正文...

---

## 随想

> 类型：随想 | 时间：2025年4月28日 10:00

正文...
```

**实现方式：** 使用 Blob + URL.createObjectURL + 触发下载。

### 4. 发帖弹窗改造（components/post/ComposeModal.tsx）

**在 textarea 上方增加：**

* 类型选择器：两个按钮 "随想" / "日记"，选中高亮

* 当选择"日记"时，显示标题输入框（placeholder: "日记标题（可选）"）

* 日记类型时字符限制放宽到 2000 字（随想保持 280 字）

**底部按钮文字改为：**

* 随想模式："发布随想"

* 日记模式："发布日记"

### 5. 帖子卡片改造（components/feed/PostCard.tsx）

**在头部区域增加类型标签：**

```
[用户名] @username · [随想|日记标签] · 2小时前
```

**标签样式：**

* 随想：小圆角标签，背景 `bg-x-blue/20`，文字 `text-x-blue`，文字 "随想"

* 日记：小圆角标签，背景 `bg-x-green/20`，文字 `text-x-green`，文字 "日记"

**当** **`title`** **存在时（日记），在内容上方显示标题：**

```
<h3 className="font-bold text-lg mb-1">{post.title}</h3>
```

**时间显示改为完整格式：**

* 卡片上显示："2025年4月28日 14:30"

* 鼠标悬停时 tooltip 显示完整 ISO 时间

**在操作栏最右侧增加导出按钮：**

* 小图标按钮，hover 显示 "导出为 Markdown"

* 点击后触发 `exportPostAsMarkdown(post)`

### 6. 主页 Feed Tab 改造（app/page.tsx）

**将 "For you" / "Following" 改为：**

* "全部" — 显示所有内容

* "随想" — 只显示 `entryType === 'thought'`

* "日记" — 只显示 `entryType === 'diary'`

### 7. 个人资料页批量导出（app/profile/page.tsx）

**在 "Edit profile" / "Follow" 按钮旁边增加：**

* "导出" 按钮（outline 样式）

* 点击后弹出小菜单：

  * 导出全部

  * 只导出日记

  * 只导出随想

  * 导出本月

  * 导出本年

### 8. Mock 数据更新（lib/mockData.ts）

**给所有现有帖子分配类型：**

* 短内容（< 100 字）→ `thought`

* 长内容（>= 100 字）→ `diary`

**新增几条专门的日记 mock 数据：**

* 带标题的日记（如 "今天学了 Next.js"）

* 长文日记（500+ 字）

* 有图片的日记

### 9. 新增组件

**components/ui/ExportButton.tsx**

* 接收 `post: Post` 参数

* 小图标按钮 + tooltip

* 点击导出单条为 .md 文件

**lib/export.ts**

* `formatDateCN(date: string): string` — 格式化为 "2025年4月28日 14:30"

* `exportPostAsMarkdown(post: Post): void` — 单条导出

* `exportPostsAsMarkdown(posts: Post[], filename: string): void` — 批量导出

   * 日记显示标题

   * 时间显示完整格式
5. 验证导出功能：

   * 单条帖子点击导出按钮，下载 .md 文件

   * 个人资料页批量导出，内容正确
6. 验证 mock 数据：

   * 现有帖子有类型标签

   * 新增日记数据正常显示

## 假设与决策

* 不引入新依赖，导出用原生 Blob API

* 日记标题可选，不强制要求

* 导出文件名格式：`日记本_2025-04-28.md` 或 `随想_标题_2025-04-28.md`

* 保持现有 UI 风格，标签用现有品牌色

* 所有数据仍用本地 state，不接入后端
