## 问题 1：Sidebar 导航图标颜色不随激活状态变化

**文件**: `components/layout/Sidebar.tsx` L112
**严重程度**: 中

### 现象
桌面端侧边栏中，无论导航项是否激活，图标颜色始终是 `text-white`（白色），无法直观区分当前所在页面。

### 代码
```tsx
<span className={isActive ? 'text-white' : 'text-white'}>
  {item.icon}
</span>
```

### 修复方案
将未激活状态的图标颜色改为 `text-x-gray`：
```tsx
<span className={isActive ? 'text-white' : 'text-x-gray'}>
  {item.icon}
</span>
```

## 问题 2：RightPanel "Who to follow" Follow 按钮状态不更新

**文件**: `components/layout/RightPanel.tsx` L129
**严重程度**: 中

### 现象
右侧栏推荐关注列表中的 Follow 按钮，点击后虽然 `toggleFollow` 会修改用户状态，但按钮文字始终显示 "Follow"，不会变为 "Following"。因为按钮渲染时没有读取 `user.isFollowed` 状态。

### 代码
```tsx
<button onClick={() => toggleFollow(user.id)} className="...">
  Follow
</button>
```

### 修复方案
根据 `user.isFollowed` 动态显示按钮文字：
```tsx
<button onClick={() => toggleFollow(user.id)} className="...">
  {user.isFollowed ? 'Following' : 'Follow'}
</button>
```

## 问题 3：PostCard 图片网格 3 张图布局异常

**文件**: `components/feed/PostCard.tsx` L100
**严重程度**: 低

### 现象
当帖子包含 3 张图片时，第一张图设置了 `row-span-2`，但 grid 容器没有设置 `grid-rows-2`，导致第一张图不会真正占据两行高度，3 张图的布局可能显示异常（第一张图高度与其他不一致）。

### 代码
```tsx
className={cn(
  'relative aspect-square',
  post.images.length === 3 && index === 0 && 'row-span-2'
)}
```

### 修复方案
在 grid 容器上添加 `grid-rows-2` 条件类：
```tsx
<div className={cn(
  'grid gap-0.5 mt-3 rounded-2xl overflow-hidden border border-x-border',
  imageGridClass,
  post.images.length === 3 && 'grid-rows-2'
)}>
```

## 问题 5：Profile 页面返回按钮无功能

**文件**: `app/profile/page.tsx` L49
**严重程度**: 低

### 现象
个人资料页顶部的返回箭头按钮没有绑定任何点击事件，点击后无反应。应该使用 `router.back()` 返回上一页。

### 修复方案
导入 `useRouter` 并绑定返回事件：
```tsx
import { useRouter } from 'next/navigation';

const router = useRouter();

<button onClick={() => router.back()} className="...">
```
