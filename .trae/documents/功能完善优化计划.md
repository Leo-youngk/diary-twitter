# 功能完善优化计划

## 摘要

基于代码审查和用户选择，对日记本项目进行功能完善优化，重点包括：

1. 搜索历史（持久化到 localStorage）
2. 发帖草稿自动保存（持久化到 localStorage）
3. 图片点击放大预览
4. 回复嵌套展示
5. 空状态优化（中文提示）
6. 导出菜单点击外部自动关闭

## 详细优化方案

### 1. localStorage 封装工具（lib/storage.ts）

**新增文件**，提供类型安全的 localStorage 读写：

```ts
const STORAGE_KEYS = {
  SEARCH_HISTORY: 'diary_search_history',
  COMPOSE_DRAFT: 'diary_compose_draft',
} as const;

export function getSearchHistory(): string[] {
  try {
    const raw = localStorage.getItem(STORAGE_KEYS.SEARCH_HISTORY);
    return raw ? JSON.parse(raw) : [];
  } catch {
    return [];
  }
}

export function addSearchHistory(query: string) {
  const history = getSearchHistory();
  const filtered = history.filter((h) => h !== query);
  const updated = [query, ...filtered].slice(0, 10);
  localStorage.setItem(STORAGE_KEYS.SEARCH_HISTORY, JSON.stringify(updated));
}

export function clearSearchHistory() {
  localStorage.removeItem(STORAGE_KEYS.SEARCH_HISTORY);
}

export interface ComposeDraft {
  content: string;
  images: string[];
  entryType: 'thought' | 'diary';
  title: string;
  savedAt: string;
}

export function getComposeDraft(): ComposeDraft | null {
  try {
    const raw = localStorage.getItem(STORAGE_KEYS.COMPOSE_DRAFT);
    return raw ? JSON.parse(raw) : null;
  } catch {
    return null;
  }
}

export function saveComposeDraft(draft: ComposeDraft) {
  localStorage.setItem(STORAGE_KEYS.COMPOSE_DRAFT, JSON.stringify(draft));
}

export function clearComposeDraft() {
  localStorage.removeItem(STORAGE_KEYS.COMPOSE_DRAFT);
}
```

* 点击历史记录直接执行搜索

## 假设与决策

* 使用原生 localStorage，不引入额外库

* 草稿保存不包括图片（URL.createObjectURL 的 blob URL 无法持久化）

* 图片预览使用简单 Modal，不引入轮播库

* 回复展示最多 3 条，超出显示"查看更多"

* 所有提示文案使用中文
